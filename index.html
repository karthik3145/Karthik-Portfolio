07 • GROWTH METHODOLOGY

How I Learn

An iterative 5-stage engineering loop designed to turn curiosity into functional, reliable hardware and software systems.

01 • STAGE

LEARN

Grasp core digital concepts, study schematics, and examine datasheets thoroughly.

02 • STAGE

EXPERIMENT

Run circuit simulations in Proteus and test breadboard wiring to validate theories.

03 • STAGE

BUILD

Assemble real hardware, wire sensors, program microcontrollers, and connect logic.

04 • STAGE

DEBUG

Understand what went wrong, probe signal pulses, test the system, and iterate.

05 • STAGE

IMPROVE

Refine timing, optimize code efficiency, and document lessons learned for the next build.
